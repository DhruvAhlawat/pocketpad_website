## Full description (2775/4000)

PocketPad mengubah HP Android kamu jadi gamepad PC wireless, keyboard dan mouse untuk PC, remote TV, dan remote presentasi, semuanya dalam satu aplikasi gratis. Pakai HP sebagai joystick untuk main game di PC tanpa perlu beli stik.

Bisa dipakai di PC (Windows / Mac / Linux), Smart TV, dan Android, tanpa perlu install apa pun di perangkat yang dikontrol.

★ HP KAMU JADI GAMEPAD
Layout gaya Xbox dan PlayStation dengan analog, trigger, D-pad, tombol LB/RB, dan ABXY. Main game PC dengan HP sebagai gamepad.
• Joystick melayang: analog muncul di tempat jempol kamu menyentuh layar
• Ketuk dua kali untuk menekan analog (L3/R3)
• Setir dengan memiringkan HP untuk game balap
• Setiap tombol bisa dipindah dan diubah ukurannya

★ KEYBOARD DAN MOUSE UNTUK PC
Touchpad besar untuk mouse, scroll dengan dua jari, tombol WASD untuk game FPS, panel ketik, dan shortcut keyboard (Ctrl+C, Alt+Tab…). Kontrol PC dari sofa.

★ REMOTE TV
Volume, putar/jeda, maju cepat, dan navigasi. Kontrol Netflix, YouTube, Plex, VLC, Kodi, dan aplikasi lain di Smart TV, Android TV, Fire TV, atau PC.

★ REMOTE PRESENTASI
PowerPoint, Google Slides, Keynote, dan Canva. Geser untuk maju atau mundur slide, tombol layar penuh, layar hitam, dan layar putih. Tidak perlu dongle atau pointer.

★ BLUETOOTH HID: TIDAK PERLU INSTALL APA PUN DI PERANGKAT
Cukup pairing sekali lewat Bluetooth dengan PC, Mac, Linux, Android, atau Smart TV, langsung siap. Tanpa driver dan tanpa software tambahan.

★ WI-FI DENGAN APLIKASI WINDOWS
Install aplikasi gratis PocketPad Companion untuk Windows: HP kamu terbaca sebagai stik Xbox lewat Wi-Fi. Langsung jalan di hampir semua game, dengan latensi paling rendah.

★ MULTIPLAYER DENGAN BEBERAPA HP
Sambungkan beberapa HP ke PC yang sama: masing-masing jadi gamepad terpisah (pemain 1, 2, 3…). Main co-op lokal bareng teman tanpa beli stik tambahan.

★ CARA PAKAI
1. Install PocketPad di HP kamu
2. Pilih Bluetooth (tanpa install apa pun) atau Wi-Fi (dengan Companion di Windows)
3. Pilih layout: gamepad, keyboard dan mouse, remote media, atau remote slide
4. Sambungkan dan langsung main

★ PERANGKAT YANG DIDUKUNG
• PC Windows 10/11: Bluetooth dan Wi-Fi (Companion)
• Mac: Bluetooth
• Linux: Bluetooth
• Android: Bluetooth
• Smart TV, Android TV, Google TV, Fire TV: Bluetooth

• Keyboard lengkap dengan shortcut, touchpad dengan scroll dua jari
