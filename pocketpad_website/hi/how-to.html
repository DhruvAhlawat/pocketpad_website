How to connect PocketPad — Bluetooth & Wi‑Fi

Connect in under a minute via Bluetooth HID (no PC install) or Wi‑Fi + Companion on Windows.

Bluetooth HID — instant pairing

  1. Install PocketPad on Android from Google Play.
  2. Open Connect → choose Bluetooth.
  3. Tap Prepare for pairing.
  4. On your PC/Mac/TV: Bluetooth settings → Add device → select your phone.
  5. Pick a layout (Gamepad, Universal, Media Remote, or Slide Controller).

Wi‑Fi + PocketPad Companion (Windows)

  1. Install Companion from the overview page (EXE installer).
  2. If the browser warns about the download, choose Keep; if Windows says “Windows protected your PC”, click More info → Run anyway.
  3. Allow private network access in Windows Firewall.
  4. Same Wi‑Fi for phone and PC.
  5. Open Companion; in PocketPad tap Connect → Wi‑Fi → your PC.
  6. For Universal layouts, enter the 6-digit code from Companion Settings.
