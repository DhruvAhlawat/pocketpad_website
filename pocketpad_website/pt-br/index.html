Para o modo controle, instale também o driver ViGEmBus gratuito para que os jogos reconheçam o celular como um controle de Xbox.

Apareceu um aviso do navegador ou do SmartScreen?

O Companion é novo, então o Windows e o navegador ainda não o reconhecem. Isso é normal com programas novos.

  1. O navegador diz que o arquivo não é baixado com frequência: abra seus downloads (Ctrl + J), abra o menu do arquivo e escolha Manter; depois, Manter assim mesmo, se perguntar.
  2. "O Windows protegeu o computador": clique em Mais informações e depois em Executar assim mesmo.
  3. Aprove o aviso do Controle de Conta de Usuário para que a instalação possa adicionar o driver ViGEmBus.

A instalação adiciona o driver de código aberto ViGEmBus só se ele estiver faltando, para que os jogos reconheçam o celular como um controle de Xbox. Para o Wi‑Fi, permita o Companion em redes privadas no Firewall do Windows.
