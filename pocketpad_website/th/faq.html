PocketPad: คำถามที่พบบ่อย

คำตอบเรื่องการใช้มือถือเป็นจอยไร้สาย คีย์บอร์ดและเมาส์ รีโมททีวี และรีโมทพรีเซนต์ คู่มือการใช้งาน · ดาวน์โหลดบน Google Play

ใช้มือถือเป็นจอยเกมได้อย่างไร

ติดตั้ง PocketPad บนมือถือ Android เปิดเลย์เอาต์จอยเกม เชื่อมต่อผ่านบลูทูธ HID (ไม่ต้องมีแอปบน PC) หรือ Wi‑Fi กับ PocketPad Companion บน Windows แล้วเล่นได้เลย

ใช้มือถือเป็นคีย์บอร์ดและเมาส์ไร้สายสำหรับ PC ได้อย่างไร

เลือกเลย์เอาต์ Universal ใน PocketPad เชื่อมต่อผ่านบลูทูธ HID หรือ Wi‑Fi เพื่อใช้ทัชแพด พิมพ์ข้อความ ปุ่ม WASD และปุ่มลัด

ใช้มือถือเป็นรีโมททีวีได้ไหม

ได้ ใช้เลย์เอาต์รีโมทสื่อของ PocketPad แล้วจับคู่ผ่านบลูทูธ HID เพื่อควบคุมเสียง การเล่น และการนำทางบนทีวีและแอปสื่อ

ใช้มือถือเป็นรีโมทพรีเซนต์หรือเลื่อนสไลด์ได้อย่างไร

ใช้เลย์เอาต์รีโมทสไลด์ของ PocketPad: ปัดเพื่อเปลี่ยนสไลด์ และใช้ปุ่มสำหรับเต็มจอ จอดำ หรือจอขาว ผ่านบลูทูธ HID

ใช้ PocketPad ได้โดยไม่ต้องติดตั้งอะไรบน PC ไหม

ได้ บลูทูธ HID ไม่ต้องใช้ซอฟต์แวร์บนอุปกรณ์ปลายทาง หากต้องการลดความหน่วงของ Wi‑Fi และเล่นหลายคนบน Windows สามารถติดตั้ง PocketPad Companion เพิ่มได้

แอปไหนดีที่สุดสำหรับใช้มือถือเป็นจอยไร้สาย

PocketPad รวมจอยเกม คีย์บอร์ด/เมาส์ รีโมททีวี และรีโมทสไลด์ไว้ในแอปเดียว รองรับบลูทูธ HID และ Wi‑Fi Companion แบบเสริมเพื่อความหน่วงต่ำและเล่นหลายคน

เชื่อมต่อมือถือหลายเครื่องเป็นจอยพร้อมกันได้ไหม

ได้ มือถือหลายเครื่องเชื่อมต่อผ่าน Wi‑Fi ด้วย PocketPad Companion แต่ละเครื่องจะแสดงเป็นจอย Xbox แยกกันบน Windows

ควรเชื่อมต่อ PocketPad ด้วยบลูทูธหรือ Wi‑Fi

ใช้บลูทูธหากต้องการจับคู่ทันทีโดยไม่ต้องติดตั้งบนอุปกรณ์ปลายทาง ใช้ Wi‑Fi กับ Companion บน Windows หากต้องการค้นหาอัตโนมัติ รหัสจับคู่ ความหน่วงที่นิ่งที่สุด และเล่นหลายคน

เชื่อมต่อ PocketPad ผ่านบลูทูธทันทีได้อย่างไร

ใน PocketPad เลือกบลูทูธ แตะ เตรียมจับคู่ เพิ่มมือถือจากการตั้งค่าบลูทูธของอุปกรณ์ปลายทาง แล้วเลือกเลย์เอาต์

เชื่อมต่อ PocketPad ผ่าน Wi‑Fi กับ Companion ได้อย่างไร

ติดตั้ง Companion บน Windows อนุญาตในไฟร์วอลล์ ใช้ Wi‑Fi เดียวกัน แล้วเชื่อมต่อจากแอป สำหรับเลย์เอาต์คีย์บอร์ด/เมาส์ Universal ให้ใส่รหัส 6 หลัก

PocketPad ใช้กับ Steam และเกม PC ได้ไหม

ได้ PocketPad จำลองจอยมาตรฐานหรือคีย์บอร์ด/เมาส์สำหรับ Steam และเกม PC ที่รองรับอุปกรณ์เหล่านั้น

PocketPad ใช้บน Mac และ Linux ได้ไหม

บลูทูธ HID ใช้บน Mac และ Linux ได้โดยไม่ต้องมีซอฟต์แวร์เพิ่ม PocketPad Companion ใช้ได้เฉพาะ Windows

ควบคุมสมาร์ททีวีหรือ Android TV ด้วย PocketPad ได้ไหม

ได้ ผ่านบลูทูธ HID ด้วยเลย์เอาต์รีโมทสื่อหรือ Universal หากทีวีรองรับอินพุต HID

PocketPad มีความหน่วงต่ำแค่ไหน

บลูทูธ HID ตอบสนองเร็วพอสำหรับเล่นเกม Wi‑Fi กับ Companion ปรับให้ความหน่วงนิ่งมากในเครือข่าย LAN เดียวกัน

ใช้มือถือเป็นจอยโดยไม่ต้องมีแอปเซิร์ฟเวอร์บนคอมพิวเตอร์ได้ไหม

ได้ โหมดบลูทูธ HID ไม่ต้องใช้เซิร์ฟเวอร์หรือ Companion บนอุปกรณ์ปลายทาง ต่างจากแอปจอยหลายตัวที่ใช้ได้แค่ Wi‑Fi

ต้องมีบัญชีเพื่อใช้ PocketPad ไหม

ไม่ต้องมีบัญชี การตั้งค่าและเลย์เอาต์จะเก็บไว้บนอุปกรณ์ของคุณ

PocketPad ใช้แบบออฟไลน์ได้ไหม

ได้ บลูทูธและ Wi‑Fi ภายใน LAN ทำงานได้โดยไม่ต้องใช้อินเทอร์เน็ต

PocketPad ฟรีไหม PocketPad Pro คืออะไร

ฟีเจอร์หลักฟรี Pro จะลบโฆษณาและเพิ่มสกินผ่านการชำระเงินของ Google Play

ทำไม Companion สำหรับ Windows ถึงพูดถึง ViGEmBus

ViGEmBus ช่วยให้ Windows มองเห็นจอย Xbox เสมือน ตัวติดตั้งจะเพิ่มให้เฉพาะเมื่อยังไม่มี

Windows หรือเบราว์เซอร์เตือนเรื่องตัวติดตั้ง Companion ปลอดภัยไหม

Companion ยังใหม่ เบราว์เซอร์และ Windows SmartScreen จึงอาจเตือน ในรายการดาวน์โหลดของเบราว์เซอร์ให้เลือก เก็บไว้ (หรือ เก็บไว้ต่อไป) ที่หน้าจอ "Windows ปกป้องพีซีของคุณ" ให้คลิก ข้อมูลเพิ่มเติม แล้ว เรียกใช้ต่อไป คุณตรวจสอบเช็กซัม SHA-256 ได้ใน README.txt

PocketPad เชื่อมต่อผ่าน Wi‑Fi ไม่ได้ ต้องตั้งค่าไฟร์วอลล์อย่างไร

อนุญาต Companion บนเครือข่ายส่วนตัวใน Windows Firewall และตรวจสอบว่ามือถือกับ PC อยู่ใน LAN เดียวกัน (ไม่ใช่ Wi‑Fi สำหรับแขกที่แยกอุปกรณ์ออกจากกัน)

PC ไม่แสดง PocketPad ในบลูทูธ ควรลองทำอะไร

แตะ เตรียมจับคู่ ในแอป ลบการจับคู่เก่า แล้วค้นหาใหม่จากการตั้งค่าบลูทูธของอุปกรณ์ปลายทาง

เกมไม่รู้จัก PocketPad เป็นจอย

ใช้เลย์เอาต์จอยเกม สำหรับ Wi‑Fi บน Windows ตรวจสอบว่า Companion และ ViGEmBus กำลังทำงาน บางเกมรองรับเฉพาะจอย XInput

ทำไมต้องจับคู่ใหม่หลังเปลี่ยนเลย์เอาต์หรือโหมด

จอยเกมกับคีย์บอร์ด/เมาส์ใช้โปรไฟล์บลูทูธ HID ต่างกัน ระบบปฏิบัติการส่วนใหญ่จึงต้องจับคู่ใหม่หลังสลับ

PocketPad เก็บข้อมูลการกดหรือเลย์เอาต์ของฉันไหม

การกดและเลย์เอาต์จะไม่ถูกส่งไปยังเซิร์ฟเวอร์ของ Datron การวิเคราะห์แบบไม่ระบุตัวตนที่เป็นตัวเลือกเสริมอธิบายไว้ในนโยบายความเป็นส่วนตัว

PocketPad คือแอป Pocket-Pad บน GitHub หรือเปล่า

PocketPad ของ Datron เป็นแอปฟีเจอร์ครบแยกต่างหาก ไม่เกี่ยวข้องกับโปรเจกต์ GitHub ที่ชื่อคล้ายกัน

ปรับแต่งเลย์เอาต์ปุ่มและสร้างพรีเซ็ตเองได้ไหม

ได้ ใช้ตัวแก้ไขเลย์เอาต์เพื่อลากและปรับขนาดปุ่ม ทำสำเนาพรีเซ็ต และบันทึกโปรไฟล์

เอียงมือถือเพื่อเลี้ยวในเกมแข่งรถได้ไหม

ได้ ฟีเจอร์เอียงเพื่อเลี้ยวจะแปลงการเอียงมือถือเป็นการหมุนพวงมาลัยในเลย์เอาต์จอยที่รองรับ
