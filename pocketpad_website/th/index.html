ไม่ต้องติดตั้ง

คู่มือตั้งค่าบลูทูธ

Wi‑Fi กับ Companion

Windows ไม่บังคับ

ความหน่วงต่ำที่สุด ค้นหา PC ของคุณได้เอง และให้มือถือสูงสุด 16 เครื่องเล่นพร้อมกัน

ดาวน์โหลดโดยตรง ดาวน์โหลดสำหรับ Windows

เวอร์ชัน 2.4.1 สำหรับ Windows 10 และ 11 (x64) ติดตั้งไดรเวอร์จอยให้อัตโนมัติ

Microsoft Store ดาวน์โหลดจาก Microsoft Store

สำหรับโหมดจอยเกม ให้ติดตั้งไดรเวอร์ ViGEmBusฟรีด้วย เพื่อให้เกมมองเห็นมือถือเป็นจอย Xbox

เจอคำเตือนจากเบราว์เซอร์หรือ SmartScreen ใช่ไหม

Companion ยังใหม่ Windows และเบราว์เซอร์จึงยังไม่รู้จัก ซึ่งเป็นเรื่องปกติของซอฟต์แวร์ใหม่

  1. เบราว์เซอร์แจ้งว่าไฟล์นี้ไม่ค่อยมีคนดาวน์โหลด: เปิดรายการดาวน์โหลด (Ctrl + J) เปิดเมนูของไฟล์แล้วเลือก เก็บไว้ จากนั้นเลือก เก็บไว้ต่อไป หากมีการถาม
  2. "Windows ปกป้องพีซีของคุณ": คลิก ข้อมูลเพิ่มเติม แล้วคลิก เรียกใช้ต่อไป
  3. อนุญาตข้อความการควบคุมบัญชีผู้ใช้ เพื่อให้ตัวติดตั้งเพิ่มไดรเวอร์ ViGEmBus ได้

ตัวติดตั้งจะเพิ่มไดรเวอร์โอเพนซอร์ส ViGEmBus เฉพาะเมื่อยังไม่มี เพื่อให้เกมมองเห็นมือถือเป็นจอย Xbox หากใช้ Wi‑Fi ให้อนุญาต Companion บนเครือข่ายส่วนตัวใน Windows Firewall

จอยของจริง บนมือถือของคุณ

อนาล็อก ทริกเกอร์ ปุ่มไหล่ และปุ่มทิศทาง เกมมองเห็นเป็นจอยของจริง จึงใช้งานได้ทันที

  • อนาล็อกลอยตัวปรากฏตรงที่นิ้วโป้งของคุณแตะ
  • กดอนาล็อกแตะอนาล็อกสองครั้งเพื่อกดลง
  • เล่นด้วยกันหลายคนมือถือสูงสุด 16 เครื่องบน PC Windows เครื่องเดียว แต่ละเครื่องเป็นจอยของตัวเอง
