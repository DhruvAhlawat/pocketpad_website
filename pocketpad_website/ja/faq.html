PocketPad：よくある質問

スマホをワイヤレスのゲームパッド、キーボードとマウス、テレビリモコン、プレゼンリモコンとして使うときの疑問に答えます。使い方ガイド · Google Play で入手。

スマホをゲームパッドやゲームコントローラーとして使うには？

Android スマホに PocketPad をインストールし、ゲームパッドのレイアウトを開きます。Bluetooth HID（PC 側のアプリは不要）か、Windows の PocketPad Companion を使った Wi‑Fi で接続すれば遊べます。

スマホを PC のリモートキーボードやマウスとして使うには？

PocketPad でユニバーサルレイアウトを選びます。Bluetooth HID か Wi‑Fi で接続すれば、タッチパッド、文字入力、WASD キー、キーボードショートカットが使えます。

スマホをテレビのリモコンとして使えますか？

はい。PocketPad のメディアリモコンレイアウトで Bluetooth HID ペアリングすれば、テレビやメディアアプリの音量、再生、操作ができます。

スマホをプレゼンやスライドのリモコンとして使うには？

PocketPad のスライドリモコンレイアウトを使います。スワイプでスライドを切り替え、ボタンで全画面表示や黒画面・白画面にできます。Bluetooth HID で接続します。

PC に何もインストールせずに PocketPad を使えますか？

はい。Bluetooth HID なら接続先にソフトは不要です。Windows で Wi‑Fi の遅延を減らしたい場合やマルチプレイをしたい場合は、PocketPad Companion を追加でインストールできます。

スマホをワイヤレスのゲームコントローラーにするおすすめアプリは？

PocketPad は、ゲームパッド、キーボード・マウス、テレビリモコン、スライドリモコンをひとつにまとめたアプリです。Bluetooth HID に加え、低遅延とマルチプレイのための Wi‑Fi Companion（任意）も使えます。

複数のスマホを同時にコントローラーとして接続できますか？

はい。PocketPad Companion を使えば複数のスマホを Wi‑Fi で接続でき、Windows ではそれぞれが別々の Xbox コントローラーになります。

PocketPad の接続は Bluetooth と Wi‑Fi のどちらがいいですか？

接続先に何もインストールせずにすぐペアリングしたいなら Bluetooth。自動検出、ペアリングコード、最小の揺らぎ、マルチプレイが必要なら、Windows で Companion を使った Wi‑Fi がおすすめです。

Bluetooth で PocketPad をすぐに接続するには？

PocketPad で Bluetooth を選び、「ペアリングの準備」をタップし、接続先の Bluetooth 設定からスマホを追加して、レイアウトを選びます。

Companion を使って Wi‑Fi で PocketPad を接続するには？

Windows に Companion をインストールし、ファイアウォールを許可して同じ Wi‑Fi につなぎ、アプリから接続します。ユニバーサル（キーボード・マウス）レイアウトでは 6 桁のコードを入力します。

PocketPad は Steam や PC ゲームで使えますか？

はい。PocketPad は標準のゲームパッドやキーボード・マウスの入力を再現するので、それらに対応した Steam や PC ゲームで使えます。

PocketPad は Mac や Linux で使えますか？

Bluetooth HID なら Mac でも Linux でも追加のソフトなしで使えます。PocketPad Companion は Windows 専用です。

PocketPad でスマートテレビや Android TV を操作できますか？

はい。テレビが HID 入力に対応していれば、Bluetooth HID とメディアリモコンまたはユニバーサルレイアウトで操作できます。

PocketPad の遅延はどのくらいですか？

Bluetooth HID はゲームでも快適な反応速度です。Companion を使った Wi‑Fi は、同じ LAN 内で揺らぎが小さくなるよう最適化されています。

PC にサーバーアプリを入れずにスマホをゲームパッドとして使えますか？

はい。Bluetooth HID モードなら、Wi‑Fi 専用の多くのコントローラーアプリと違い、接続先にサーバーも Companion も不要です。

PocketPad を使うのにアカウントは必要ですか？

アカウントは不要です。設定とレイアウトは端末内に保存されます。

PocketPad はオフラインで使えますか？

はい。Bluetooth と LAN 内の Wi‑Fi はインターネットなしで使えます。

PocketPad は無料ですか？PocketPad Pro とは？

基本機能は無料です。Pro は Google Play の決済で、広告を非表示にし、見た目のスキンを追加します。

Windows 版 Companion で ViGEmBus が出てくるのはなぜ？

ViGEmBus があると、Windows が仮想 Xbox コントローラーを認識できます。インストーラーは入っていない場合にだけ追加します。

Companion のインストーラーで Windows やブラウザーが警告します。安全ですか？

Companion はまだ新しいので、ブラウザーや Windows SmartScreen が警告することがあります。ブラウザーのダウンロード一覧で「保存」（または「保存する」）を選んでください。「Windows によって PC が保護されました」画面では「詳細情報」、続けて「実行」をクリックします。README.txt で SHA-256 チェックサムを確認できます。

PocketPad が Wi‑Fi で接続できません。ファイアウォールの対処法は？

Windows ファイアウォールでプライベートネットワークでの Companion の通信を許可し、スマホと PC が同じ LAN にあること（機器同士を隔離するゲスト用 Wi‑Fi ではないこと）を確認してください。

PC の Bluetooth に PocketPad が表示されません。どうすれば？

アプリで「ペアリングの準備」をタップし、古いペアリング情報を削除してから、接続先の Bluetooth 設定でもう一度検索してください。

ゲームが PocketPad をコントローラーとして認識しない

ゲームパッドのレイアウトを使ってください。Windows の Wi‑Fi 接続では、Companion と ViGEmBus が動作していることを確認してください。XInput コントローラーにしか対応していないゲームもあります。

レイアウトやモードを切り替えた後に、もう一度ペアリングが必要なのはなぜ？

ゲームパッドとキーボード・マウスでは Bluetooth HID のプロファイルが異なるため、ほとんどの OS では切り替え後に再ペアリングが必要です。

PocketPad はコントローラーの入力やレイアウトを収集しますか？

コントローラーの入力やレイアウトが Datron のサーバーに送られることはありません。任意の匿名分析についてはプライバシーポリシーで説明しています。

PocketPad は GitHub の Pocket-Pad アプリと同じものですか？

Datron の PocketPad は別のフル機能アプリで、似た名前の GitHub プロジェクトとは関係ありません。

ボタン配置をカスタマイズして自分のプリセットを作れますか？

はい。レイアウトエディターでボタンをドラッグしたりサイズを変えたり、プリセットを複製してプロファイルとして保存できます。

スマホを傾けてレースゲームのハンドル操作ができますか？

はい。傾けてハンドル操作する機能で、対応するゲームパッドレイアウトではスマホの傾きがハンドル操作になります。
