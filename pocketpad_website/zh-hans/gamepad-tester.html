手柄测试：在线免费测试游戏手柄按键和摇杆

插上（或配对）手柄，实时检查每个 按键、摇杆、扳机键 和 方向键。一切都在浏览器中完成，不用下载，也不上传任何数据。在怪游戏之前，先用这个在线手柄测试工具快速确认手柄是否正常。

与 Windows 自带的 测试 USB 游戏控制器 窗口不同，本页面会 同时显示所有已连接的手柄，并排展示，每个都有实时画面。当蓝牙 HID 或多手柄环境出现多个手柄、你想逐个确认时，非常实用。

手柄测试器使用方法

  1. 通过 USB 或 蓝牙 连接手柄（Windows、Mac、Linux 或 ChromeOS）。
  2. 按任意键或推动摇杆，对应的控件会亮起，数值实时更新。
  3. 如果一开始检测不到，先按一下按键；有些浏览器要等第一次输入才会唤醒手柄。
  4. 连接多个手柄时，每个都有自己的卡片。一直停在 尚无输入 的卡片值得检查。

测试任何手柄：Xbox、PlayStation、Switch、通用 HID

支持 Xbox、PlayStation、Switch Pro、通用 USB HID 手柄，以及 Windows 上 PocketPad Companion 创建的虚拟手柄等。标准 Xbox 布局可直接对应；在 PlayStation 风格手柄上，屏幕标签按每个按键的 位置 显示，所以符号（✕/△/◯/▢）看起来可能会错位，以每个手柄下方的原始按键编号为准。

测试你的 PocketPad

蓝牙：在 Android 手机上运行 PocketPad，点按 准备配对，从电脑配对后，在这里按几个键试试。Wi‑Fi + Companion：通过 Wi‑Fi 连接的 PocketPad 手机会在这里各自显示为独立的虚拟手柄，即使系统测试窗口只显示第一个。
