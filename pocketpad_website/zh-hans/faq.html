PocketPad：常见问题

关于把手机当作无线手柄、键盘和鼠标、电视遥控器和演示翻页器的解答。使用指南 · 在 Google Play 下载。

怎样把手机当作游戏手柄或游戏控制器？

在 Android 手机上安装 PocketPad，打开手柄布局，通过蓝牙 HID（电脑上不用装应用）或配合 Windows 版 PocketPad Companion 用 Wi‑Fi 连接，就能开玩。

怎样把手机当作电脑的无线键盘和鼠标？

在 PocketPad 中选择通用布局。通过蓝牙 HID 或 Wi‑Fi 连接，即可使用触控板、打字、WASD 键和键盘快捷键。

可以把手机当电视遥控器吗？

可以。使用 PocketPad 的媒体遥控布局，通过蓝牙 HID 配对，即可控制电视和媒体应用的音量、播放和导航。

怎样把手机当作演示或幻灯片翻页器？

使用 PocketPad 的翻页器布局：滑动切换幻灯片，按键实现全屏和黑屏/白屏，通过蓝牙 HID 连接。

电脑上不安装任何软件也能用 PocketPad 吗？

可以。蓝牙 HID 不需要主机安装软件。若想在 Windows 上降低 Wi‑Fi 延迟或多人游戏，可选装 PocketPad Companion。

用手机当无线游戏手柄，哪个应用最好？

PocketPad 集手柄、键盘/鼠标、电视遥控器和翻页器于一身，支持蓝牙 HID，并可选用 Wi‑Fi Companion 实现低延迟和多人游戏。

可以同时连接多部手机作为手柄吗？

可以。配合 PocketPad Companion，多部手机可通过 Wi‑Fi 连接，在 Windows 上各自显示为独立的 Xbox 手柄。

连接 PocketPad 用蓝牙还是 Wi‑Fi？

想要即刻配对、主机不装软件就用蓝牙。需要自动发现、配对码、最低抖动和多人游戏，就在 Windows 上配合 Companion 用 Wi‑Fi。

怎样用蓝牙快速连接 PocketPad？

在 PocketPad 中选择蓝牙，点按“准备配对”，从主机的蓝牙设置添加手机，然后选择布局。

怎样配合 Companion 用 Wi‑Fi 连接 PocketPad？

在 Windows 上安装 Companion，允许防火墙，连接同一 Wi‑Fi，从应用中连接；使用通用键盘/鼠标布局时输入 6 位数配对码。

PocketPad 支持 Steam 和电脑游戏吗？

支持。PocketPad 模拟标准手柄或键盘/鼠标输入，适用于支持这些设备的 Steam 和电脑游戏。

PocketPad 能在 Mac 和 Linux 上用吗？

蓝牙 HID 在 Mac 和 Linux 上无需额外软件即可使用。PocketPad Companion 仅适用于 Windows。

能用 PocketPad 控制智能电视或 Android TV 吗？

可以。只要电视支持 HID 输入，就能通过蓝牙 HID 配合媒体遥控或通用布局来控制。

PocketPad 的延迟有多低？

蓝牙 HID 响应迅速，足以玩游戏；配合 Companion 的 Wi‑Fi 针对同一局域网的低抖动做了优化。

电脑上不装服务端，也能把手机当手柄吗？

可以。与许多只支持 Wi‑Fi 的手柄应用不同，蓝牙 HID 模式不需要在主机上装服务端或 Companion。

使用 PocketPad 需要账号吗？

不需要账号。设置和布局保存在你的设备上。

PocketPad 能离线使用吗？

能。蓝牙和局域网 Wi‑Fi 不需要联网。

PocketPad 免费吗？PocketPad Pro 是什么？

核心功能免费。Pro 通过 Google Play 付费，去除广告并增加外观皮肤。

为什么 Windows 版 Companion 提到 ViGEmBus？

ViGEmBus 让 Windows 识别虚拟 Xbox 手柄。只有在缺少时安装程序才会添加。

Windows 或浏览器对 Companion 安装程序发出警告，安全吗？

Companion 是新软件，所以浏览器和 Windows SmartScreen 可能会发出警告。在浏览器的下载列表中选择“保留”（或“仍然保留”）。在“Windows 已保护你的电脑”界面点击“更多信息”，再点“仍要运行”。你可以在 README.txt 中核对 SHA-256 校验和。

PocketPad 用 Wi‑Fi 连不上，防火墙怎么设置？

在 Windows 防火墙中允许 Companion 访问专用网络，并确认手机和电脑在同一局域网（不是隔离设备的访客 Wi‑Fi）。

电脑的蓝牙里没有显示 PocketPad，该怎么办？

在应用中点按“准备配对”，清除旧的配对记录，再从主机的蓝牙设置重新搜索。

游戏不把 PocketPad 识别为手柄

使用手柄布局；在 Windows 上用 Wi‑Fi 时，确认 Companion 和 ViGEmBus 正在运行。有些游戏只支持 XInput 手柄。

切换布局或模式后为什么要重新配对？

手柄和键盘/鼠标使用不同的蓝牙 HID 配置文件，大多数系统在切换后需要重新配对。

PocketPad 会收集我的手柄输入或布局吗？

手柄输入和布局不会发送到 Datron 的服务器。可选的匿名分析在隐私政策中有说明。

PocketPad 和 GitHub 上的 Pocket-Pad 应用是同一个吗？

Datron 的 PocketPad 是独立的全功能应用，与名称相似的 GitHub 项目无关。

可以自定义按键布局、创建自己的预设吗？

可以。用布局编辑器拖动、调整控件大小，复制预设并保存为配置。

可以倾斜手机来玩赛车游戏吗？

可以。体感转向会在支持的手柄布局中，把手机的倾斜映射为方向盘操作。
