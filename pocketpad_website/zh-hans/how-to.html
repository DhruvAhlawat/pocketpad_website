PocketPad 连接教程：蓝牙与 Wi‑Fi

通过 蓝牙 HID（电脑无需安装）或 Windows 上的 Wi‑Fi + Companion，一分钟内即可连上。

蓝牙 HID：即刻配对

  1. 从 Google Play 在 Android 上安装 PocketPad。
  2. 打开“连接” → 选择 蓝牙。
  3. 点按 准备配对。
  4. 在电脑、Mac 或电视上：蓝牙设置 → 添加设备 → 选择你的手机。
  5. 选择布局（手柄、通用、媒体遥控或翻页器）。

Wi‑Fi + PocketPad Companion（Windows）

  1. 从 概览页面 安装 Companion（EXE 安装程序）。
  2. 如果浏览器提示下载有风险，选择 保留；如果 Windows 提示“Windows 已保护你的电脑”，点击 更多信息 → 仍要运行。
  3. 在 Windows 防火墙中允许访问专用网络。
  4. 手机和电脑连同一个 Wi‑Fi。
  5. 打开 Companion；在 PocketPad 中点按“连接” → Wi‑Fi → 你的电脑。
  6. 使用通用布局时，输入 Companion 设置中的 6 位数配对码。
