Test Your Gamepad Online — Free Gamepad & Controller Tester

Plug in (or pair) a controller and check every button, analog stick, trigger, and D‑pad live — all in your browser, with no download and no upload. This online gamepad tester is a quick way to confirm a controller works before you blame a game.

Unlike Windows' built-in Test USB game controllers dialog, this page shows every connected gamepad at once, side by side, with its own live visual. That makes it a useful check when Bluetooth HID or a multi-pad setup exposes several controllers and you want to verify each one independently.

How to use the gamepad tester

  1. Connect a gamepad via USB or Bluetooth (Windows, Mac, Linux, or ChromeOS).
  2. Press any button or move a stick — the matching control lights up and its value updates live.
  3. If nothing detects at first, press a button once; some browsers only wake a pad after its first input.
  4. With multiple pads connected, each one gets its own card. A card stuck on No input yet is worth investigating.

Test any controller — Xbox, PlayStation, Switch, generic HID

Works with Xbox, PlayStation, Switch Pro, generic USB HID pads, and virtual controllers such as those created by the PocketPad Companion on Windows. Standard Xbox-style layouts map as expected; on PlayStation-style pads the on-screen labels follow the position of each button, so glyphs (✕/△/◯/▢) may look rearranged — the raw button numbers below each pad are the ground truth.

Testing your PocketPad setup

Bluetooth: run PocketPad on your Android phone, tap Prepare for pairing, pair from your PC, then play a few buttons here. Wi‑Fi + Companion: PocketPad phones connected over Wi‑Fi appear here as their own virtual controllers — even when the system test dialog would only show the first one.
