Windows용 PocketPad Companion의 새로운 기능

Wi‑Fi 연결, 실시간 대시보드, 멀티플레이를 위한 선택형 Windows 앱 PocketPad Companion의 릴리스 노트입니다. 최신 버전부터 표시합니다.

예전 Companion을 쓰고 계신가요? 휴대폰은 계속 작동하지만, 업데이트하면 이 수정 사항을 받을 수 있습니다. 최신 Companion 다운로드.

버전 2.4.1

출시 2026년 9월 26일

더 큰 게임 모임과 훨씬 안정적인 연결.

새 기능

  • 휴대폰이나 컨트롤러를 최대 16대까지 동시에 연결할 수 있습니다(기존 4대). 예전 Xbox 컨트롤러 방식을 쓰는 게임은 처음 4대만 인식하지만, 대부분의 최신 게임과 Steam은 모두 인식합니다.

개선

  • Companion을 열면 바로 휴대폰 연결을 기다립니다. 시작을 누를 필요가 없습니다.
  • ViGEmBus 컨트롤러 드라이버가 없거나 휴대폰이 PC를 찾는 데 쓰는 포트를 다른 앱이 쓰고 있을 때 경고가 더 명확해졌습니다.
  • 대시보드에 이 PC의 IP 주소가 표시되어, 휴대폰이 PC를 자동으로 찾지 못할 때 직접 연결할 수 있습니다. 휴대폰에 필요한 주소(Wi‑Fi 또는 이더넷)가 먼저 표시되고, VPN과 Tailscale, WSL 같은 가상 어댑터는 "다른 주소 보기" 안에 정리됩니다.
  • 네트워크 어댑터가 여러 개인 PC(예: Wi‑Fi와 이더넷 또는 VPN)가 휴대폰 목록에 두 번 나타나지 않습니다.
  • 혼잡한 Wi‑Fi에서도 연결이 더 안정적입니다. 도중에 사라진 메시지는 자동으로 다시 보냅니다.
  • 다시 연결한 휴대폰은 게임패드 번호를 유지하므로 플레이어 2는 계속 플레이어 2입니다.

수정

  • 같은 핫스팟에 있거나 하나의 네트워크 주소를 공유하는 휴대폰 2대 이상이 하나의 컨트롤러를 함께 쓰거나 연결되지 않는 문제가 있었습니다. 이제 휴대폰마다 항상 자기 컨트롤러를 받습니다.
  • Wi‑Fi가 잠깐 끊긴 뒤 휴대폰이 "연결됨"으로 보이지만 버튼이 작동하지 않을 수 있었습니다. 이제 스스로 복구합니다(예전 버전의 휴대폰 앱은 대신 "연결 끊김"을 표시하므로 다시 연결하면 됩니다).
  • 페어링 코드를 바꾸거나 새로 만들어도 게임패드 레이아웃을 쓰는 휴대폰은 끊기지 않습니다. 새 코드는 키보드·마우스 휴대폰에만 필요합니다.

버전 2.3.1

출시 2026년 9월 15일

여러 휴대폰 동시 연결 시 멀티플레이 수정.

개선

  • 휴대폰이 연결되면 첫 버튼을 누르기 전에도 바로 Windows에 컨트롤러가 나타납니다.
  • 대시보드의 게임패드 1, 2, 3… 목록이 누가 버튼을 누를 때마다 뒤섞이지 않고 고정된 순서를 유지합니다.

수정

  • 여러 휴대폰이 연결되면 컨트롤러가 뒤바뀔 수 있었습니다. 이제 휴대폰마다 확실히 자기 컨트롤러를 조작합니다.
  • 한 휴대폰의 컨트롤러에 문제가 생겨도 그 휴대폰만 영향을 받고, 다른 사람은 계속 플레이할 수 있습니다.

버전 2.3.0

출시 2026년 9월 13일

Android용 PocketPad 5.1에 맞춰 업데이트.

개선

  • PocketPad 5.1 휴대폰 앱을 지원하며, 전반적인 안정성을 개선했습니다.

버전 2.2.1

출시 2026년 9월 13일

가운데 클릭과 더 나은 호환성.

새 기능

  • 키보드·마우스(유니버설) 레이아웃에서 마우스 가운데 버튼을 지원합니다.

개선

  • Companion이 실행 중인 버전을 휴대폰 앱에 알려 줍니다.

수정

  • 예전 PocketPad 5.0.0과 5.0.1 휴대폰 앱에서도 제대로 작동합니다.

버전 2.2.0

출시 2026년 9월 3일

더 부드러운 기울여서 조향.

개선

  • 가속이나 브레이크를 놓으면 바로 반영되어 레이싱 조작이 더 민첩해졌습니다.

수정

  • 기울여서 조향을 쓰는 동안 누르고 있는 버튼과 조향이 깜빡이지 않습니다.
  • 대시보드의 스틱 미리보기가 손을 떼면 바로 가운데로 돌아옵니다.

버전 2.1.3

출시 2026년 9월 2일

새 기능

  • 대시보드에 설치된 Companion 버전이 표시됩니다.

버전 2.1.2

출시 2026년 8월 2일

개선

  • 앱에 Companion 버전을 표시하기 위한 내부 업데이트.

버전 2.1.1

출시 2026년 7월 31일

개선

  • 안정성과 호환성을 높이기 위해 구성 요소를 업데이트했습니다.

버전 2.1.0

출시 2026년 7월 26일

Wi‑Fi에서 기울여서 조향.

새 기능

  • 이제 Companion을 쓰는 Wi‑Fi에서도 기울여서 조향이 작동합니다. 휴대폰을 기울여 레이싱 게임을 조종하세요.

개선

  • 휴대폰이 입력을 빠르게 많이 보내도 Wi‑Fi 입력 지연이 더 낮고 안정적입니다.
  • 휴대폰이 많은 입력을 보내는 동안에도 대시보드가 빠르게 반응합니다.

수정

  • 휴대폰의 작은 터치 오류 때문에 누르고 있던 버튼과 스틱이 잠깐 풀리는 일이 없어졌습니다.
  • 휴대폰이 다시 연결된 직후 입력이 빠지지 않습니다.

버전 2.0.0

출시 2026년 7월 13일

개선

  • 새로워진 PocketPad 휴대폰 앱에 맞춘 새 버전 번호.

버전 1.2.0

출시 2026년 7월 12일

선택형 페어링 코드.

새 기능

  • 키보드·마우스(유니버설) 레이아웃에 페어링 코드를 쓸지 선택할 수 있습니다. 믿을 수 있는 집 네트워크에서는 끄면 내 휴대폰 어느 것이든 코드 없이 연결됩니다. 선택은 기억됩니다.

개선

  • 페어링 코드가 언제 필요한지 설명하는 화면 도움말이 더 명확해졌습니다. 게임패드 레이아웃에는 코드가 필요 없습니다.
