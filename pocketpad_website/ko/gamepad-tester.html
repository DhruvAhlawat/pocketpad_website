게임패드 테스터: 브라우저에서 무료로 컨트롤러 테스트하기

컨트롤러를 연결(또는 페어링)하고 모든 버튼, 아날로그 스틱, 트리거, 방향 패드를 실시간으로 확인하세요. 모두 브라우저 안에서 처리되며 다운로드도 업로드도 없습니다. 게임 탓을 하기 전에 컨트롤러가 정상인지 빠르게 확인할 수 있는 온라인 게임패드 테스터입니다.

Windows 기본 USB 게임 컨트롤러 테스트 창과 달리, 이 페이지는 연결된 모든 게임패드를 동시에 나란히 보여 주고 각각의 입력을 실시간으로 표시합니다. 블루투스 HID나 여러 패드 구성에서 컨트롤러가 여러 개 잡혀 하나씩 확인하고 싶을 때 유용합니다.

게임패드 테스터 사용법

  1. 게임패드를 USB나 블루투스로 연결하세요(Windows, Mac, Linux, ChromeOS).
  2. 아무 버튼이나 누르거나 스틱을 움직이면 해당 부분이 켜지고 값이 실시간으로 바뀝니다.
  3. 처음에 아무것도 감지되지 않으면 버튼을 한 번 누르세요. 일부 브라우저는 첫 입력이 있어야 패드를 인식합니다.
  4. 여러 패드를 연결하면 각각 카드가 하나씩 생깁니다. 아직 입력 없음에 머문 카드는 확인해 볼 필요가 있습니다.

Xbox, PlayStation, Switch, 일반 HID 등 모든 컨트롤러 테스트

Xbox, PlayStation, Switch Pro, 일반 USB HID 패드, Windows의 PocketPad Companion이 만드는 가상 컨트롤러 등에서 작동합니다. 표준 Xbox 스타일 배치는 그대로 대응됩니다. PlayStation 스타일 패드에서는 화면 라벨이 각 버튼의 위치를 따르므로 기호(✕/△/◯/▢)가 바뀌어 보일 수 있습니다. 각 패드 아래의 실제 버튼 번호가 정확한 기준입니다.

PocketPad 설정 테스트

블루투스: Android 휴대폰에서 PocketPad를 실행하고 페어링 준비를 탭한 뒤 PC에서 페어링하고, 여기서 버튼 몇 개를 눌러 보세요. Wi‑Fi + Companion: Wi‑Fi로 연결된 PocketPad 휴대폰은 각각 독립된 가상 컨트롤러로 여기에 나타납니다. 시스템 테스트 창이 첫 번째 것만 보여 줄 때도 마찬가지입니다.
