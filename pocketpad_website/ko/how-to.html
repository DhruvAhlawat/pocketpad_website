PocketPad 연결 방법: 블루투스와 Wi‑Fi

블루투스 HID(PC 설치 불필요) 또는 Windows의 Wi‑Fi + Companion으로 1분 안에 연결하세요.

블루투스 HID: 바로 페어링

  1. Google Play에서 Android에 PocketPad를 설치합니다.
  2. 연결을 열고 블루투스를 선택합니다.
  3. 페어링 준비를 탭합니다.
  4. PC, Mac, TV에서: 블루투스 설정 → 기기 추가 → 휴대폰 선택.
  5. 레이아웃을 선택합니다(게임패드, 유니버설, 미디어 리모컨, 슬라이드 리모컨).

Wi‑Fi + PocketPad Companion(Windows)

  1. 개요 페이지에서 Companion을 설치합니다(EXE 설치 파일).
  2. 브라우저가 다운로드를 경고하면 유지를 선택하고, "Windows의 PC 보호"가 나타나면 추가 정보 → 실행을 클릭합니다.
  3. Windows 방화벽에서 개인 네트워크 액세스를 허용합니다.
  4. 휴대폰과 PC는 같은 Wi‑Fi에.
  5. Companion을 열고, PocketPad에서 연결 → Wi‑Fi → PC를 탭합니다.
  6. 유니버설 레이아웃에서는 Companion 설정에 표시된 6자리 코드를 입력합니다.
