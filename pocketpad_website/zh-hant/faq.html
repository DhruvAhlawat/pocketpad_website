PocketPad：常見問題

關於把手機當作無線手把、鍵盤和滑鼠、電視遙控器和簡報翻頁器的解答。使用指南 · 在 Google Play 下載。

要怎麼把手機當作遊戲手把或遊戲控制器？

在 Android 手機上安裝 PocketPad，開啟手把配置，透過藍牙 HID（電腦上不用裝 App）或搭配 Windows 版 PocketPad Companion 用 Wi‑Fi 連線，就能開始玩。

要怎麼把手機當作電腦的無線鍵盤和滑鼠？

在 PocketPad 中選擇通用配置。透過藍牙 HID 或 Wi‑Fi 連線，就能使用觸控板、打字、WASD 鍵和鍵盤快速鍵。

可以把手機當電視遙控器嗎？

可以。使用 PocketPad 的媒體遙控配置，透過藍牙 HID 配對，就能控制電視和媒體 App 的音量、播放和導覽。

要怎麼把手機當作簡報或投影片翻頁器？

使用 PocketPad 的簡報筆配置：滑動切換投影片，按鈕可切換全螢幕和黑畫面/白畫面，透過藍牙 HID 連線。

電腦上不安裝任何軟體也能用 PocketPad 嗎？

可以。藍牙 HID 不需要主機軟體。若想在 Windows 上降低 Wi‑Fi 延遲或多人遊戲，可以選用 PocketPad Companion。

用手機當無線遊戲手把，哪個 App 最好？

PocketPad 集手把、鍵盤/滑鼠、電視遙控器和簡報筆於一身，支援藍牙 HID，並可選用 Wi‑Fi Companion 達到低延遲和多人遊戲。

可以同時連接多支手機當作手把嗎？

可以。搭配 PocketPad Companion，多支手機可透過 Wi‑Fi 連線，在 Windows 上各自顯示為獨立的 Xbox 手把。

連接 PocketPad 要用藍牙還是 Wi‑Fi？

想立即配對、主機不裝軟體就用藍牙。需要自動偵測、配對碼、最低抖動和多人遊戲，就在 Windows 上搭配 Companion 用 Wi‑Fi。

要怎麼用藍牙快速連接 PocketPad？

在 PocketPad 中選擇藍牙，點選「準備配對」，從主機的藍牙設定新增手機，然後選擇配置。

要怎麼搭配 Companion 用 Wi‑Fi 連接 PocketPad？

在 Windows 上安裝 Companion，允許防火牆，連上同一個 Wi‑Fi，從 App 連線；使用通用鍵盤/滑鼠配置時輸入 6 位數配對碼。

PocketPad 支援 Steam 和電腦遊戲嗎？

支援。PocketPad 模擬標準手把或鍵盤/滑鼠輸入，適用於支援這些裝置的 Steam 和電腦遊戲。

PocketPad 能在 Mac 和 Linux 上用嗎？

藍牙 HID 在 Mac 和 Linux 上不需要額外軟體。PocketPad Companion 僅支援 Windows。

能用 PocketPad 控制智慧電視或 Android TV 嗎？

可以。只要電視支援 HID 輸入，就能透過藍牙 HID 搭配媒體遙控或通用配置來控制。

PocketPad 的延遲有多低？

藍牙 HID 反應靈敏，足以玩遊戲；搭配 Companion 的 Wi‑Fi 針對同一區域網路的低抖動做了最佳化。

電腦上不裝伺服器程式，也能把手機當手把嗎？

可以。和許多只支援 Wi‑Fi 的手把 App 不同，藍牙 HID 模式不需要在主機上安裝伺服器或 Companion。

使用 PocketPad 需要帳號嗎？

不需要帳號。設定和配置都儲存在你的裝置上。

PocketPad 可以離線使用嗎？

可以。藍牙和區域網路 Wi‑Fi 不需要網際網路。

PocketPad 免費嗎？PocketPad Pro 是什麼？

核心功能免費。Pro 透過 Google Play 付款，移除廣告並加入外觀主題。

為什麼 Windows 版 Companion 會提到 ViGEmBus？

ViGEmBus 讓 Windows 能辨識虛擬 Xbox 手把。只有在缺少時安裝程式才會加入。

Windows 或瀏覽器對 Companion 安裝程式發出警告，安全嗎？

Companion 是新軟體，所以瀏覽器和 Windows SmartScreen 可能會發出警告。在瀏覽器的下載清單中選擇「保留」（或「仍要保留」）。在「Windows 已保護您的電腦」畫面按一下「其他資訊」，再按「仍要執行」。你可以在 README.txt 中核對 SHA-256 總和檢查碼。

PocketPad 用 Wi‑Fi 連不上，防火牆怎麼設定？

在 Windows 防火牆中允許 Companion 存取私人網路，並確認手機和電腦在同一個區域網路（不是會隔離裝置的訪客 Wi‑Fi）。

電腦的藍牙沒有顯示 PocketPad，該怎麼辦？

在 App 中點選「準備配對」，清除舊的配對紀錄，再從主機的藍牙設定重新搜尋。

遊戲沒有把 PocketPad 辨識為手把

使用手把配置；在 Windows 上用 Wi‑Fi 時，確認 Companion 和 ViGEmBus 正在執行。有些遊戲只支援 XInput 手把。

切換配置或模式後為什麼要重新配對？

手把和鍵盤/滑鼠使用不同的藍牙 HID 設定檔，大多數作業系統在切換後需要重新配對。

PocketPad 會收集我的手把輸入或配置嗎？

手把輸入和配置不會傳送到 Datron 的伺服器。選用的匿名分析在隱私權政策中有說明。

PocketPad 和 GitHub 上的 Pocket-Pad App 是同一個嗎？

Datron 的 PocketPad 是獨立的完整功能 App，與名稱相似的 GitHub 專案無關。

可以自訂按鍵配置、建立自己的預設嗎？

可以。用配置編輯器拖曳、調整控制項大小，複製預設並儲存為設定檔。

可以傾斜手機玩賽車遊戲嗎？

可以。體感轉向會在支援的手把配置中，把手機的傾斜轉換成方向盤操作。
