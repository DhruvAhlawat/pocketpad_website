手把測試：線上免費測試遊戲手把按鍵和搖桿

插上（或配對）手把，即時檢查每個 按鈕、類比搖桿、板機鍵 和 方向鍵。全部在瀏覽器中完成，不用下載，也不會上傳。在怪遊戲之前，先用這個線上手把測試工具快速確認手把是否正常。

和 Windows 內建的 測試 USB 遊戲控制器 視窗不同，這個頁面會 同時顯示所有已連接的手把，並排呈現，每個都有即時畫面。當藍牙 HID 或多手把環境出現多個手把、你想逐一確認時，非常實用。

手把測試器使用方式

  1. 透過 USB 或 藍牙 連接手把（Windows、Mac、Linux 或 ChromeOS）。
  2. 按任一按鈕或推動搖桿，對應的控制項會亮起，數值即時更新。
  3. 如果一開始偵測不到，先按一下按鈕；有些瀏覽器要等第一次輸入才會喚醒手把。
  4. 連接多個手把時，每個都有自己的卡片。一直停在 尚無輸入 的卡片值得檢查。

測試任何手把：Xbox、PlayStation、Switch、通用 HID

支援 Xbox、PlayStation、Switch Pro、通用 USB HID 手把，以及 Windows 上 PocketPad Companion 建立的虛擬手把等。標準 Xbox 配置可直接對應；在 PlayStation 風格手把上，畫面標籤依每個按鈕的 位置 顯示，所以符號（✕/△/◯/▢）看起來可能會錯位，以每個手把下方的原始按鈕編號為準。

測試你的 PocketPad

藍牙：在 Android 手機上執行 PocketPad，點選 準備配對，從電腦配對後，在這裡按幾個按鈕試試。Wi‑Fi + Companion：透過 Wi‑Fi 連線的 PocketPad 手機會在這裡各自顯示為獨立的虛擬手把，即使系統測試視窗只顯示第一個。
