PocketPad 連線教學：藍牙與 Wi‑Fi

透過 藍牙 HID（電腦不必安裝）或 Windows 上的 Wi‑Fi + Companion，一分鐘內就能連上。

藍牙 HID：立即配對

  1. 從 Google Play 在 Android 上安裝 PocketPad。
  2. 開啟「連線」→ 選擇 藍牙。
  3. 點選 準備配對。
  4. 在電腦、Mac 或電視上：藍牙設定 → 新增裝置 → 選擇你的手機。
  5. 選擇配置（手把、通用、媒體遙控或簡報筆）。

Wi‑Fi + PocketPad Companion（Windows）

  1. 從 總覽頁面 安裝 Companion（EXE 安裝程式）。
  2. 如果瀏覽器警告這個下載，選擇 保留；如果 Windows 顯示「Windows 已保護您的電腦」，按一下 其他資訊 → 仍要執行。
  3. 在 Windows 防火牆中允許存取私人網路。
  4. 手機和電腦連同一個 Wi‑Fi。
  5. 開啟 Companion；在 PocketPad 中點選「連線」→ Wi‑Fi → 你的電腦。
  6. 使用通用配置時，輸入 Companion 設定中的 6 位數配對碼。
