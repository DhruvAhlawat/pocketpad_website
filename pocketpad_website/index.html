After you install

  1. Run the installer (not a separate script).
  2. If SmartScreen says unsigned: More info → Run anyway.
  3. Firewall: allow on private networks so your phone can reach the PC.
  4. Then open PocketPad on your phone, same Wi‑Fi, and connect.

Universal controller (keyboard & mouse)

WASD, touchpad for the cursor, click buttons, optional fullscreen + type, and a 6-digit code from the PC for secure keyboard/mouse sessions.
