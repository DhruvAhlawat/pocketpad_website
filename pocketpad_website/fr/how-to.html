Connecter PocketPad  Bluetooth et Wi‑Fi

Connexion en moins d’une minute via Bluetooth HID (rien à installer sur le PC) ou Wi‑Fi + Companion sous Windows.

Bluetooth HID  association immédiate

  1. Installez PocketPad sur Android depuis Google Play.
  2. Ouvrez Connexion → choisissez Bluetooth.
  3. Touchez Préparer l’association.
  4. Sur votre PC, Mac ou TV  paramètres Bluetooth → Ajouter un appareil → sélectionnez votre téléphone.
  5. Choisissez une disposition (Manette, Universelle, Télécommande multimédia ou Télécommande de diapos).

Wi‑Fi + PocketPad Companion (Windows)

  1. Installez Companion depuis la page de présentation (programme d’installation EXE).
  2. Si le navigateur signale le téléchargement, choisissez Conserver  si Windows affiche « Windows a protégé votre ordinateur , cliquez sur Informations complémentaires → Exécuter quand même.
  3. Autorisez l’accès aux réseaux privés dans le pare-feu Windows.
  4. Même Wi‑Fi pour le téléphone et le PC.
  5. Ouvrez Companion  dans PocketPad, touchez Connexion → Wi‑Fi → votre PC.
  6. Pour les dispositions Universelles, saisissez le code à 6 chiffres des paramètres de Companion.
