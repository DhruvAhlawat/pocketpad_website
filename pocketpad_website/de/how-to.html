PocketPad verbinden: Bluetooth und WLAN

In unter einer Minute verbunden: per Bluetooth HID (keine Installation am PC) oder per WLAN + Companion unter Windows.

Bluetooth HID: sofort koppeln

  1. Installiere PocketPad auf Android aus Google Play.
  2. Öffne Verbinden → wähle Bluetooth.
  3. Tippe auf Kopplung vorbereiten.
  4. Am PC, Mac oder Fernseher: Bluetooth-Einstellungen → Gerät hinzufügen → dein Handy wählen.
  5. Wähle ein Layout (Gamepad, Universal, Medienfernbedienung oder Presenter).

WLAN + PocketPad Companion (Windows)

  1. Installiere Companion von der Übersichtsseite (EXE-Installationsprogramm).
  2. Warnt der Browser vor dem Download, wähle Beibehalten; meldet Windows „Der Computer wurde durch Windows geschützt“, klicke auf Weitere Informationen → Trotzdem ausführen.
  3. Erlaube in der Windows-Firewall den Zugriff auf private Netzwerke.
  4. Handy und PC im selben WLAN.
  5. Öffne Companion; tippe in PocketPad auf Verbinden → WLAN → deinen PC.
  6. Gib bei Universal-Layouts den 6-stelligen Code aus den Companion-Einstellungen ein.
