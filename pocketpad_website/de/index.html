Warnung vom Browser oder von SmartScreen?

Companion ist neu, deshalb kennen Windows und dein Browser es noch nicht. Das ist bei neuer Software normal.

  1. Der Browser meldet, dass die Datei nicht häufig heruntergeladen wird: Öffne deine Downloads (Strg + J), öffne das Menü der Datei und wähle Beibehalten, dann bei Nachfrage Trotzdem beibehalten.
  2. „Der Computer wurde durch Windows geschützt“: Klicke auf Weitere Informationen und dann auf Trotzdem ausführen.
  3. Bestätige die Abfrage der Benutzerkontensteuerung, damit das Setup den ViGEmBus-Treiber hinzufügen kann.

Das Setup fügt den Open-Source-Treiber ViGEmBus nur hinzu, wenn er fehlt, damit Spiele dein Handy als Xbox-Controller erkennen. Für WLAN erlaube Companion in der Windows-Firewall für private Netzwerke.
