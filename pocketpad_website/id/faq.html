PocketPad: pertanyaan umum

Jawaban seputar memakai HP sebagai gamepad nirkabel, keyboard dan mouse, remote TV, dan remote presentasi. Panduan penggunaan · Download di Google Play.

Bagaimana cara memakai HP sebagai gamepad atau stik game?

Instal PocketPad di HP Android. Buka tata letak gamepad, sambungkan lewat Bluetooth HID (tanpa aplikasi di PC) atau Wi‑Fi dengan PocketPad Companion di Windows, lalu main.

Bagaimana cara memakai HP sebagai keyboard dan mouse jarak jauh untuk PC?

Pilih tata letak Universal di PocketPad. Sambungkan lewat Bluetooth HID atau Wi‑Fi untuk touchpad, mengetik, tombol WASD, dan pintasan keyboard.

Bisakah HP dipakai sebagai remote TV?

Bisa. Gunakan tata letak Remote media di PocketPad dan pasangkan lewat Bluetooth HID untuk mengatur volume, pemutaran, dan navigasi di TV dan aplikasi media.

Bagaimana cara memakai HP sebagai remote presentasi atau slide?

Gunakan tata letak Remote slide di PocketPad: geser untuk ganti slide dan pakai tombol untuk layar penuh serta layar hitam atau putih lewat Bluetooth HID.

Apakah PocketPad bisa dipakai tanpa instal apa pun di PC?

Bisa. Bluetooth HID tidak butuh software di perangkat tujuan. Kalau mau latensi Wi‑Fi lebih rendah dan main bareng di Windows, kamu bisa menginstal PocketPad Companion.

Aplikasi apa yang paling bagus untuk menjadikan HP stik game nirkabel?

PocketPad menggabungkan gamepad, keyboard/mouse, remote TV, dan remote slide, dengan Bluetooth HID serta Wi‑Fi Companion opsional untuk latensi rendah dan main bareng.

Bisakah beberapa HP tersambung sebagai kontroler sekaligus?

Bisa. Beberapa HP tersambung lewat Wi‑Fi dengan PocketPad Companion; masing-masing muncul sebagai kontroler Xbox terpisah di Windows.

Sebaiknya PocketPad disambungkan lewat Bluetooth atau Wi‑Fi?

Pakai Bluetooth untuk langsung terpasang tanpa instal di perangkat tujuan. Pakai Wi‑Fi dengan Companion di Windows untuk deteksi otomatis, kode penyandingan, latensi paling stabil, dan main bareng.

Bagaimana cara langsung menyambungkan PocketPad lewat Bluetooth?

Di PocketPad pilih Bluetooth, ketuk Siapkan penyandingan, tambahkan HP dari pengaturan Bluetooth perangkat tujuan, lalu pilih tata letak.

Bagaimana cara menyambungkan PocketPad lewat Wi‑Fi dengan Companion?

Instal Companion di Windows, izinkan di firewall, gunakan Wi‑Fi yang sama, dan sambungkan dari aplikasi; masukkan kode 6 digit untuk tata letak keyboard/mouse Universal.

Apakah PocketPad bisa dipakai di Steam dan game PC?

Bisa. PocketPad meniru gamepad standar atau keyboard/mouse untuk Steam dan game PC yang mendukung perangkat tersebut.

Apakah PocketPad bisa dipakai di Mac dan Linux?

Bluetooth HID bisa dipakai di Mac dan Linux tanpa software tambahan. PocketPad Companion hanya untuk Windows.

Bisakah saya mengontrol Smart TV atau Android TV dengan PocketPad?

Bisa, lewat Bluetooth HID dengan tata letak Remote media atau Universal, kalau TV mendukung input HID.

Seberapa rendah latensi PocketPad?

Bluetooth HID responsif untuk main game; Wi‑Fi dengan Companion dioptimalkan agar latensi sangat stabil di jaringan lokal yang sama.

Bisakah HP dipakai sebagai gamepad tanpa aplikasi server di komputer?

Bisa. Mode Bluetooth HID tidak butuh server atau Companion di perangkat tujuan, tidak seperti banyak aplikasi kontroler yang hanya lewat Wi‑Fi.

Apakah perlu akun untuk memakai PocketPad?

Tidak perlu akun. Pengaturan dan tata letak disimpan di perangkat kamu.

Apakah PocketPad bisa dipakai offline?

Bisa. Bluetooth dan Wi‑Fi jaringan lokal berjalan tanpa internet.

Apakah PocketPad gratis? Apa itu PocketPad Pro?

Fitur utamanya gratis. Pro menghilangkan iklan dan menambah skin lewat pembayaran Google Play.

Kenapa Companion untuk Windows menyebut ViGEmBus?

ViGEmBus membuat Windows bisa melihat kontroler Xbox virtual. Penginstal hanya menambahkannya kalau belum ada.

Windows atau browser memperingatkan penginstal Companion. Apakah aman?

Companion masih baru, jadi browser dan Windows SmartScreen mungkin memperingatkannya. Di daftar unduhan browser, pilih Simpan (atau Tetap simpan). Di layar "Windows melindungi PC Anda", klik Info selengkapnya, lalu Tetap jalankan. Kamu bisa mencocokkan checksum SHA-256 di README.txt.

PocketPad tidak tersambung lewat Wi‑Fi. Bagaimana mengatur firewall?

Izinkan Companion di jaringan pribadi pada Windows Firewall dan pastikan HP dan PC ada di jaringan lokal yang sama (bukan Wi‑Fi tamu yang memisahkan perangkat).

PC saya tidak menampilkan PocketPad di Bluetooth. Apa yang harus dicoba?

Ketuk Siapkan penyandingan di aplikasi, hapus penyandingan lama, lalu cari lagi dari pengaturan Bluetooth perangkat tujuan.

Game saya tidak mengenali PocketPad sebagai kontroler

Gunakan tata letak gamepad; untuk Wi‑Fi di Windows, pastikan Companion dan ViGEmBus berjalan. Beberapa game hanya menerima kontroler XInput.

Kenapa harus memasangkan ulang setelah ganti tata letak atau mode?

Gamepad dan keyboard/mouse memakai profil Bluetooth HID yang berbeda; kebanyakan sistem operasi meminta penyandingan ulang setelah berpindah.

Apakah PocketPad mengumpulkan input atau tata letak saya?

Input dan tata letak tidak dikirim ke server Datron. Analitik anonim opsional dijelaskan di Kebijakan Privasi.

Apakah PocketPad sama dengan aplikasi Pocket-Pad di GitHub?

PocketPad dari Datron adalah aplikasi lengkap tersendiri, tidak terkait dengan proyek GitHub yang namanya mirip.

Bisakah saya mengatur tata letak tombol dan membuat preset sendiri?

Bisa. Gunakan editor tata letak untuk menggeser dan mengubah ukuran kontrol, menggandakan preset, dan menyimpan profil.

Bisakah saya menyetir game balap dengan memiringkan HP?

Bisa. Fitur setir dengan memiringkan HP mengubah posisi HP menjadi gerakan setir di tata letak gamepad yang didukung.
