Cara kerja PocketPad

PocketPad punya dua jalur: Bluetooth HID (tanpa Companion di perangkat tujuan) dan Wi‑Fi / Companion opsional di Windows untuk deteksi, dasbor, dan main bareng. Dapatkan aplikasi Android di Google Play.

Bluetooth HID

  • Tanpa instal di perangkat yang mendukung penyandingan HID standar.
  • Berpindah antara mode gamepad dan keyboard/mouse mungkin perlu penyandingan ulang.
  • Remote media dan TV bisa dipakai dengan Smart TV dan aplikasi media.

Wi‑Fi Companion (Windows)

  • PocketPad Companion opsional untuk deteksi, kode penyandingan, dan dasbor langsung.
  • Main bareng: banyak HP sebagai kontroler Xbox terpisah.
  • Download penginstal dari halaman ringkasan hanya kalau kamu butuh fitur Wi‑Fi.

Mode kontrol

  • Tata letak kustom, setir dengan memiringkan HP, keyboard dan mouse Universal, mode presentasi dan media.
