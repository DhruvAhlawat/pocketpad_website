Как подключить PocketPad: Bluetooth и Wi‑Fi

Подключение меньше чем за минуту: Bluetooth HID (без установки на ПК) или Wi‑Fi + Companion в Windows.

Bluetooth HID: мгновенное сопряжение

  1. Установите PocketPad на Android из Google Play.
  2. Откройте «Подключение» → выберите Bluetooth.
  3. Нажмите «Подготовить сопряжение».
  4. На ПК, Mac или телевизоре: настройки Bluetooth → Добавить устройство → выберите телефон.
  5. Выберите раскладку («Геймпад», «Универсальная», «Медиапульт» или «Пульт для слайдов»).

Wi‑Fi + PocketPad Companion (Windows)

  1. Установите Companion со страницы обзора (установщик EXE).
  2. Если браузер предупреждает о загрузке, выберите «Сохранить»; если Windows пишет «Система Windows защитила ваш компьютер», нажмите «Подробнее» → «Выполнить в любом случае».
  3. Разрешите доступ к частным сетям в брандмауэре Windows.
  4. Телефон и ПК в одной сети Wi‑Fi.
  5. Откройте Companion; в PocketPad нажмите «Подключение» → Wi‑Fi → ваш ПК.
  6. Для универсальных раскладок введите 6-значный код из настроек Companion.
