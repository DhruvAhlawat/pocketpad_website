Inside the archive you get the Flutter `runner/Release` output. After extracting:

  1. Run pc_companion_ui.exe once and allow private-network firewall access.
  2. Install ViGEmBus separately if you need virtual Xbox controller emulation (see companion README).
  3. On your phone open PocketPad, stay on the same Wi-Fi, tap Connect.

Microsoft Store listings will supersede manual downloads eventually — the PocketPad homepage notes where the Store badge will appear.
